# Flozi Privacy Policy

Effective date: October 15, 2026

Flozi is a local macOS companion made by Ahmad Zaki. It shows animated avatars and coarse activity from local Codex sessions.

## Your activity stays on your Mac

Flozi does not send your chats, prompts, tool commands, reasoning, outputs, project names, or session data to the developer or any server. The app has no analytics, advertising, tracking, account registration, or in-app purchases. It makes no network requests. Opening the optional support or privacy links uses your browser, where the linked site's privacy policy applies.

## Folder access

The App Store build asks you to choose a local Codex sessions folder using the macOS folder picker. Access is read-only. Codex session files can contain chat content and tool results; Flozi parses those files locally to recognize event types, then discards content it does not need. It retains only session identifiers, project folder names, timestamps, and coarse activity state in memory. It does not display or retain prompt text, reasoning text, tool arguments, commands, or outputs.

Activity is inferred from the last observed log events and may be delayed or incomplete. It does not monitor ChatGPT or remote/cloud Codex tasks.

## Settings and control

Avatar, volume, and sound preferences are saved in the app's local preferences. A security-scoped bookmark remembers the folder you chose. You can change the folder or select Disconnect folder in Settings. Disconnecting removes the saved bookmark and stops monitoring that folder; it does not delete Codex files. Quitting stops the app. No background helper is installed.

## Contact

For privacy questions or support, open an issue at [github.com/ahmdzzzki/flozi/issues](https://github.com/ahmdzzzki/flozi/issues). Please avoid posting private chats, logs, credentials, or personal information in public issues.

## Changes

Updates to this policy will be published with a revised effective date in the Flozi repository.
